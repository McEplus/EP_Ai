# 射击径向聚焦模糊

## 定位与边界

目标是第一人称有效开火时，中心可辨识、外围沿屏幕中心射线短促虚化，具有向外传播的冲击感。这是当前帧空间缩放模糊，不是依赖历史帧或运动向量的真实运动模糊。

先确认用户追求的参考：PS“径向模糊—缩放”、局部高斯软化和旋转模糊不是同一种效果。不要用 FOV 动画、曝光增加或长距离离散重影替代缩放模糊。

本技能不固定项目目录、枪包路径或环境版本。先搜索后处理注册、材质引用、fragment shader、有效射击链路、设置与测试，确定当前实现，再调整。不要顺便改后坐力、火光、枪械动作或命中逻辑。

## 数据流与生命周期

- 仅在接受有效射击的链路触发；无弹、冷却拒绝、空击不触发。霰弹每次扳机射击触发一次，不按弹丸重复触发。
- 每发保存开始时间与幅度，新发不能重置旧波的进度。固定少量槽位，超限替换最旧项；单个活跃 Timer，不逐发创建循环 Timer。
- 使用绝对经过时间计算传播与衰减，低帧率不能延长尾迹。无活动波后关闭后处理与 Timer。
- 第一人称、开关、画质限制、强度为零和销毁清理要独立校验；保留已有第三人称、死亡、UI/世界退出保护。
- 设置默认值、UI 范围、非法值回退、首次初始化和运行中同步保持一致。枪焰粒子和照明开关不应控制模糊。
- 动态注册要幂等，明确与热成像、照明、泛光的执行顺序。不能仅凭注册成功判断最终合成正确。
- 先验证引擎注入的屏幕尺寸 uniform 及 render target 分辨率，不能只声明变量就假定引擎提供了值。

## Shader 方法

1. 焦点通常为 UV 中心。用 `length(vec2(delta.x * aspect, delta.y))` 计算圆形清晰区遮罩，以 smoothstep 软过渡。圆形距离用于遮罩，UV 采样射线仍使用原始 `delta = uv - center`，避免重复宽高比修正。
2. 缩放采样使用 `uv - delta * zoomAmount * t`；像素离焦点越远，位移越大。沿射线密集加权采样，不要用四周邻域采样冒充缩放模糊。
3. 有限预算可用原图加八个等距采样，共九次读取，三角权重为 `1,2,3,4,5,4,3,2,1`，除以 25。原图采样复用，不再多读一次。
4. 限制整段采样的像素长度，UV 使用 Clamp，避免边缘黑色与巨大分离拖影。该方案九点、24 像素全段上限意味着相邻点最多 3 像素；这只能减少重影风险，不保证所有纹理都连续。
5. 保留原始 alpha、亮度归一化，不主动加入曝光、暗角、色差。中心及微弱区域提前返回原图，但不要宣称 GPU 必然按比例省时，分支收益须实测。
6. 若用户仍需更长且更密的模糊，先讨论采样质量与性能预算，考虑降采样或分级方案；不要无限放大固定少量采样的距离。

## 传播与衰减必须分开调

边缘模糊弱时，先分析波前到达时刻，不要首先增加采样数。

一个已遇到的问题：生命周期为 0.10 秒，传播进度直接使用归一化寿命，衰减却从寿命 45% 开始。四角接近波前时强度已经很低，中心附近能看到波，外围几乎没有效果。延长寿命虽能掩盖问题，却违反快速消散要求。

可用独立传播比例：
- `t = age / duration`
- `travel = clamp(t / travelFraction, 0, 1)`
- `front = clearRadius + travel * (cornerRadius + waveWidth - clearRadius)`
- 环带突出波前，波后区域保留一定覆盖，再乘本发时间包络。
- 让传播完成早于明显衰减开始；同时检查最慢目标帧率下是否至少有一帧出现明显边缘模糊。

初始调参示例（不是通用强制值）：
- 持续 0.10 秒，进入 0.012 秒；传播比例 0.35，即约 0.035 秒覆盖四角。
- 波宽 0.22，以屏幕高度归一化距离计；波后覆盖权重 0.85。
- 保留旧平滑尾迹，在寿命 45% 后衰减到零。
- 四个波槽位，一只约 60 Hz 的活跃 Timer。
这些是经过静态/数值回归的实现起点，不代表已获用户实机验收。

## 默认强度不能被重复压低

若滑块同时控制距离、混合比例，又用混合权重缩短距离，默认 0.5 可能被多次相乘后看不见。分别检查：
- 波包络幅度；
- 空间遮罩和环带覆盖；
- 原图/模糊图混合比例；
- 采样长度；
- 单枪倍率与 ADS 系数。

可采用 `strengthGain = sqrt(clamp(strength, 0, 1))` 提高中档可见度，零值仍严格关闭。示例使用距离比例 `0.09 * strengthGain`，像素全段上限 `mix(16,24,strengthGain)`，默认 0.5 时上限约 21.7 像素；实际距离仍受位置与包络缩放。不要把“距离上限”写成所有像素的实际模糊长度。

提高强度后检查枪口高亮区域是否被空间采样扩散，但不通过改曝光补偿模糊。镜内发白应先做独立开关 A/B：关闭模糊仍亮时，转查枪口照明、透明几何、深度/alpha 标记，而不是继续盲改模糊。

## 验证与交付

- 自动测试：零强度与非法设置、单发/连射、槽位上限、单 Timer、生命周期清理、ADS/逐枪倍率及拒绝射击。
- Shader/数值检查：采样总数、权重归一化、中心原图、UV 边界、alpha 保留；默认强度下四边及四角是否在衰减前被覆盖，30/60/120 FPS 的停止时限是否一致。
- 覆盖不同宽高比和分辨率。固定像素上限在高分辨率下的视觉角度更小，需实机判断是否适合；不要未经确认无限按分辨率放大。
- 实机比较 0、0.5、1.0，腰射/瞄准、单发/连射、低后坐力枪/重枪，以及照明/热成像叠加。动态传播必须看视频或连帧，单张截图不能验证整个包络。
- 保持源码修改范围，编译与测试避免遗留缓存；不自动重载、不修改构建发布目录。
- 明确报告静态通过、GPU 编译、性能实测、用户观感分别是否完成。九采样单 pass 是预算描述，不是“没有性能影响”的证据。
