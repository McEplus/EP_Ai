# basp_tf 离线细节换色实验

**历史记录：实验已推广为正式版本。下文中的实验开关、专用控制器、旧生成脚本和前置包测试资源均已退役。当前维护请使用 [推广记录](../rollout.md)及 [HTML 批处理工具](../../../tools/mask-batch/README.md)。本目录的对比图和指标仅保留为实验参考。**

## 范围

实验默认开启，仅在基础图为 `textures/models/basp_tf` 且选区图为对应原图时接入。其它皮肤、枪械、配件继续使用上一版算法；未启用 RGB 染色的选区仍显示原图。金属度、粗糙度、玻璃度、炫彩度的数据协议不变。

原始基础图和选区图均未修改，附属包配置也未改写。生成图位于主包 `textures/pbr/detail/basp_tf_color_mask.png`，尺寸 174x88，PNG 为 3095 字节。运行时替换原选区图，不新增采样槽或 pass；资源缓存总量由游戏管理，不能据此保证重载时只缓存一份。

## 制作方法

1. 根据原选区图 RGB 识别五区，忽略 alpha 对区域身份的影响。
2. 在有效基础像素内建立各区的连通区域，局部滤波不跨不同选区或不相连的区域。
3. 在对数亮度空间离线计算归一化高斯基础层，局部半径 6 像素、sigma 2。使用 80% 局部基础与 20% 选区中位亮度作为基准，保留一部分较大尺度的变化。
4. 将原亮度与基准的相对差异编码为细节系数，主体中心约 0.90。暗纹保留较强的下降，亮纹平滑接近 0.99，避免硬截为白色。
5. RGB 沿原选区颜色比例存放细节系数，非零通道最小为 8，避免区域变成纯黑而失效。alpha 逐像素原样保留。

这不是从贴图中完美识别真实 AO 或材质类别。相邻且同色的不同 UV 面仍可能被视为一个连通区域，需要游戏内检查接缝；微小凹槽和大面积固有深色也可能无法完全区分。

## 运行时

`EPLUS_MASK_DETAIL` 为专用材质的编译期分支。染色结果为目标 RGB 乘以选区图最大 RGB 通道；本分支不再附加原色残差、强制冷色或依赖原图亮度的提亮曲线。随后沿用现有 PBR 光照和反射。

只有 `controller.render.ep_item_color_detail` 使用此分支。配件依旧使用普通选区材质，因此同一实体共享 uniform 不会使配件误读实验编码。普通、流畅、兼容各有材质变体，兼容源文件未修改。

回退方式：将 `pbrMaskRender.py` 中 `DETAIL_MASK_EXPERIMENT` 设为 `False`，重新加载脚本和资源。绑定函数会恢复原选区图与普通控制器，不需要重存皮肤。此开关不改变用户保存数据。

## 对比与验证

[基础颜色对比图](comparison.png)：每行分别为纯白、中灰 141、红色；每行三列为原图、上一版、实验版。这是 UV 贴图上的无光照对比，不是枪械模型截图，也不代表最终游戏光照。

`metrics.json` 保存源文件哈希、生成尺寸和受光前选区的误差统计。白色平均绝对目标误差从约 0.250 降至 0.148，中灰从约 0.280 降至 0.082。误差降低只说明更接近目标颜色，不单独证明细节质量。

已通过：

- 4 项离线资产测试：底色亮度归一化、五区身份与 alpha 保留、凹槽/磨损排序、相邻不同选区隔离。
- 11 项 Python 2.7 渲染与配色测试，包括实验开关、皮肤切换回退和三档材质选择。
- 桌面离屏 GLSL 实验分支编译、1590 组生成纹理/选色像素检查、金属度和原图回归。
- 上一版 GLSL 路径的像素测试，材质和控制器配置解析，跨包绑定检查。

尚未验证游戏完整 shader 编译、实际模型表现、移动 GLES 和帧耗时。先在 basp_tf 上分别测试纯白、中灰、红色，并检查默认皮肤、PBR-only 编辑、保存重进、第一/第三人称和掉落；重点观察亮面细节、凹槽、UV 接缝，以及反射是否仍覆盖纹理。

## 重建

在原工作站用 Python 3 + Pillow 运行 `tools/build_basp_detail_mask.py`。工具从 EP 工作区解析来源，只读取原图，写入主包生成图与本目录报告。使用 Python 2.7 运行 `tests/test_pbr_mask_material.py`；离线资产测试与 `tools/check_pbr_mask_gl.py --detail-mask` 使用 Python 3。
