# R101 白色涂装受光校正

## 当前版本：分离底色受光与反射

### 参数响应与计算复用

默认/流畅已进一步调整：高金属度环境响应使用单调、不过早封顶的二次曲线；粗糙度覆盖完整范围，不再在默认主 PBR 的 0.78 处提前封顶。环境模糊按粗糙度平方映射到原有范围（默认 0.20–0.80、流畅 0.24–0.82），保留低粗糙度的清晰感并拉开高粗糙度差异。

涂装底色只在金属度超过约 0.55 后逐步增加反射余量，低粗糙度时作用较强；中段选色基准保持。实际材质值仍由原有 78% 用户值与 22% 纹理值混合产生，UI 的 0 仍表示自动。

环境路径复用法线、视线、反射方向和天空可见度；底色函数复用已有 NdotL，不重复求法线点积。环境采样入口去掉多余的方向归一化。现有入口函数签名保留，默认 5 次、流畅 3 次环境采样不减少，也不增加 pass、纹理或 uniform。

新增六档金属度/粗糙度扫描及同底色、同光照下的换色响应检查，结果在 `parameter-response-default.json` 和 `parameter-response-fast.json`。受控白色案例默认朝上/侧面/朝下约为 0.855/0.676/0.396，流畅约为 0.878/0.686/0.410。参数范围调整与性能源码优化均已通过 GLSL 离屏检查，但未测量游戏或移动设备帧率，不能把减少重复运算等同于已测出的 FPS 提升。

默认与流畅模式已停止对整个 PBR 结果进行曝光映射。现在由 `eplusSurfaceLighting.h` 的 `epPaintDiffuse` 只校正漫反射/涂装底色，再单独叠加直接高光、环境反射、金属亮带和边缘光。受光明暗由法线朝向天空及光源的连续系数控制，较光滑金属为反射保留一定亮度余量。

原始未换色 PBR 同样减少侧面及朝下表面的环境补光：默认模式主要调整间接漫反射，流畅模式降低弱受光面的填充；环境反射仅轻微减弱朝下表面的宽泛补光，直接高光不会被统一压暗。原 `pbrPreset` / `pbrPresetEnv` 及 Fast 接口保留，由零涂装权重的包装函数兼容现有材质。

全局源贴图、alpha 金属度、粗糙度参数、离线工具与已有选区图无需重做。没有新增采样、pass、uniform 或屏幕深度算法。兼容模式保持上一版调用链，`eplusPBRBalance.h` 未改。

新增离屏检查覆盖形体对比和环境图响应：受控默认模式白色材质朝上/侧面/朝下约为 0.856/0.676/0.397，流畅约为 0.877/0.688/0.410。切换测试环境图亮度时，默认模式未涂装校正/已涂装校正的输出变化为 0.260/0.259，流畅为 0.118/0.119，说明环境反射变化没有被染色曝光挤平。这不是游戏截图测量，实际表现及帧耗时仍需实测。

下文保留第一版整体曝光校正的排查记录；其中 `epMaskPaintExposure` 当前仅用于兼容模式。

## 排查结果

读取军工7 `twx_r101_color_mask.png` 的有效选区，细节系数中位数分别约为 R 0.880、G 0.922、B 0.886；basp_tf 对应值约为 0.902、0.878、0.902。两者都已正确转换为 detail-v1，R101 并非因为原始颜色偏暗而无法生成明亮的染色底色。

在选纯白时，shader 输入 PBR 的主体颜色已经接近白色；后续金属反射、漫反射权重、环境光与亮度限制共同决定最终输出。原先只测试了离线选区图及基础颜色，没有覆盖完整 PBR 输出，所以没有暴露“底色很白、游戏中仍呈灰色”的问题。

## 实施

新增 `epMaskPaintExposure`，只对真正启用 RGB 染色的表面做艺术化受光曝光校正。金属度、粗糙度、贴图和默认未染色外观不变。

以 `shaded / max(albedo, 0.04)` 估计每个颜色通道的受光倍率，将小于 1 的倍率平滑向 1 提升，然后还原颜色。大于 1 的已有高光不额外放大，零亮度仍为零；不是往画面叠加白色。

校正强度随当前片段的场景光亮度在 0.18 到 0.65 之间平滑启用，最大曝光参数为 15。它以颜色匹配为目的，并非新的物理涂层 BRDF；可能压缩部分受光明暗差异，游戏内仍需检查形体层次。

染色表面暂时把 PBR 的雾强度设为零，校正完成后再应用原雾，避免提升雾色或远处泛白。未染色表面维持原雾链路。`eplusPBRBalance.h` 未修改。没有新增采样、pass、纹理、深度算法或 Python 参数。

不需要重新处理已经生成的选区图，HTML 工具的 detail-v1 输出仍然有效。

## 验证

`tools/check_pbr_mask_gl.py` 现在编译实际默认/流畅/兼容 PBR 头文件，默认和流畅使用现有环境图。引擎 include 由测试环境省略，雾用显式线性混合桩替代，因此不是游戏完整编译的替代品。

受控案例：原图灰度 0.18、细节 0.9、金属度 0.46、场景光 0.7、朝向相机的法线，默认 PBR 输出从约 `(0.475, 0.498, 0.522)` 提升为 `(0.851, 0.855, 0.859)`。这些是离屏条件，不是从用户截图测出的游戏实际数值。

测试覆盖细节分离、亮部、暗场景、零光、完整雾、未染色回归与三档材质编译。输出数据见本目录三个 JSON 文件。

仍需游戏内验证：R101 的纯白/中灰/饱和色，白天/洞穴/夜晚，金属度 0（自动）与手动高金属度，以及光照方向改变时的形体层次。尚未测量移动端帧耗时。
