三步，完成资源导入。

  1. 选择项目文件夹

    用 Edge 或 Chrome 打开本网页。复制项目路径，在文件夹选择窗口的地址栏粘贴，选择项目根目录。工具会自动识别其中的资源包。

  2. 拖入 bbmodel，补全标识符

    支持批量导入。标识符示例：geometry.ep.lockpick。缺失时会阻止导入；可在卡片里补填，也可以回 Blockbench 的项目设置修改。

  3. 确认目录，预览并导入

    三个目录分别接收模型 JSON、动画 JSON 和 PNG。点击“预检并导入”查看实际文件清单，再写入项目。也可以导出 ZIP 后手动解压到项目。

当前支持立方体模型、骨骼层级、单张内嵌 PNG、定位器，以及线性 / 阶梯 / Catmull-Rom 动画。网格、多贴图混用、旋转 UV、Bezier 动画等暂不支持的内容会明确拦截。bbmodel 中的材质图像导出为 PNG，不生成引擎着色器 .material 文件，也不自动创建实体、物品或动画绑定。
