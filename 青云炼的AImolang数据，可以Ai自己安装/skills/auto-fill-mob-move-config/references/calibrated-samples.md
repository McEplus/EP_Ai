## 样本边界

本文件记录 2026-08-08 当前工作树的实体 Python 与导出动画。用户已确认两只生物的攻击判定、位移和特效在客户端表现上对齐，因此它们用于提炼模式；这里的精确数值仍是物种/动作样本，不是所有生物的默认值。

## 共同规律

### root motion

逐段积分结果都回到同一标尺：

```text
anim X -> local X
anim Y -> local Y
anim -Z -> local +Z
motion_scale ≈ 0.00527
```

| 生物/动作 | 代码位移积分 | 动画根净位移映射 | 隐含 scale |
|---|---:|---:|---:|
| 监守者一段 | `(0,0,0.14228)` | `(0,0,27)` | `0.005270` |
| 监守者冲刺 | `(0,-0.00015,0.84322)` | `(0,0,160)` | `0.005270` |
| 监守者潜行二段 | `(-0.00016,0,0.37425)` | `(0,0,71)` | `0.005271` |
| 铁傀儡一段 | `(0,0,0.09620)` | `(0,0,18)` | `0.005344`（两位功率舍入） |
| 铁傀儡冲刺 | `(0,0,0.40400)` | `(0,0,76.5)` | `0.005281` |
| 铁傀儡潜行二段 | `(0,0,0.81676)` | `(0,0,155)` | `0.005269` |

差异主要来自代码方向/功率保留两到四位小数；不是每招另有一个尺度。

### 时序与表现

- 单次挥击的拳风通常在命中前 `0～0.08s`。
- 砸地烟尘通常在命中前 `0.08s` 到后 `0.20s`。
- `AttackTime` 常比最后创建攻击盒晚约 `0.1～0.2s`，给攻击授权和短扫描留余量。
- `UnControlTime` 晚于攻击窗口，`StateKeepTime` 覆盖收势，`StateAnimTime` 负责完整视觉尾帧。
- 旋转/持续接触拆成密集低伤盒，最终冲击再使用独立强盒。

## 监守者

### 状态窗口与攻击

| 动作 | Attack/UnControl/Keep/Anim | 创建攻击盒 | 主要判定语义 |
|---|---|---|---|
| 一段 | `0.8/1.0/1.3/1.8` | `0.70` | `range 3.2, 180°, rotate.z=20` 单侧横扫 |
| 二段 | `0.8/1.0/1.2/1.6` | `0.70` | `range 3.2, 180°, rotate.z=-20` 反侧横扫 |
| 三段 | `0.9/1.2/2.0/2.5` | `0.71` | `range 4, 180°, rotate.z=-90` 重下挥 |
| 冲刺 | `0.6/1.0/1.1/2.5` | `0.70` | `range 4, 180°` 高速推进冲击 |
| 处决 | `2.0/2.2/2.5/3.3` | `0.25, 1.88` | 首击控制；末击为 20 长度地面长廊 |
| 潜行一段 | `1.1/1.2/1.5/2.5` | `1.04` | 20 长度地面长廊 |
| 潜行二段 | `2.3/2.5/2.8/3.0` | `0.25, 1.17, 2.13` | 两次定向控制，末段 `range 5, 360°` |

### 明确关系

- 一/二段的 `rotate.z` 正负相反，对应交替挥击侧；拳风与命中同帧。
- 三段拳风 `0.70`、攻击 `0.71`、烟尘 `0.71`，三层信号围绕同一重击峰值。
- 冲刺 root 净位移为 160 动画单位，服务器积分为 `0.8432`；峰值功率 `2.0623` 来自动画首段爆发，不是统一限幅。
- 处决末击和潜行一段都使用 `range=2, radians=360, high=20, high_type=up, rotate=(-90,0,0)`。`rotate.x=-90` 把高度轴转到地面前方，十个 `DirtSmoke` 分别沿 `z=2,4,...,20` 铺满长廊。
- 处决烟尘覆盖 `1.80～1.98s`，围绕 `1.88s` 命中前后展开；潜行一段烟尘覆盖 `1.00～1.18s`，围绕 `1.04s` 展开。
- 潜行二段在三处独立肢体/躯干速度峰创建攻击盒，不保留共享状态的密集连击盒。

## 铁傀儡

### 状态窗口与攻击

| 动作 | Attack/UnControl/Keep/Anim | 创建攻击盒 | 主要判定语义 |
|---|---|---|---|
| 一段 | `0.7/0.9/1.0/1.25` | `0.58` | `range 3.5, 180°, rotate.z=60` 重横扫 |
| 二段 | `0.5/0.7/1.0/1.5` | `0.38` | `range 3.5, 180°, rotate.z=-10` 反侧横扫 |
| 三段 | `0.8/1.0/1.5/2.75` | `0.71` | `range 2, 360°, high_type=up, rotate.x=-90` 近身下砸 |
| 冲刺 | `1.0/1.2/1.3/1.65` | `0.33, 0.85` | 两次 `range 3.5, 260°` 持续冲击 |
| 处决 | `1.3/1.4/1.5/1.8` | `0.58, 1.17` | 首次横扫，末次 300° 地面冲击 |
| 潜行一段 | `0.8/1.2/1.3/1.55` | `0.58` | `range 4, 240°` 双臂同步重击 |
| 潜行二段 | `1.4/1.6/2.0/2.3` | `0.10..0.80` 每 0.1、`1.17` | 360°低伤旋转连击 + 定向终结 |

### 明确关系

- 一段拳风 `0.55`、攻击 `0.58`、烟尘 `0.60`，形成前置风压—接触—落尘的 `-0.03/0/+0.02s` 次序。
- 二段拳风比攻击早 `0.08s`；三段只早 `0.01s`，重击越明确越接近同帧。
- 冲刺两个接触峰各有独立拳风；第二峰 `0.85` 后在 `0.90` 配下砸音效与烟尘。
- 潜行一段左右各一股拳风，和动画双臂同步下落一致；烟尘延后到 `0.75` 表示落地，不等同于 `0.58` 的空中接触帧。
- 潜行二段动画 root yaw 在前段连续跨越多圈，因此使用 `0.10～0.80` 的八个 `360°` 低伤盒；`1.17` 再创建方向性终结盒。
- 潜行二段显式关闭共享 `State_Motion/State_Attack` 后调用 `EmptyAttackSneaking2.onStart`，因此仍继承共享拳风、音爆、声音和镜头。自动填参必须展开这条继承链，避免误以为本类“没有特效”。

## 当前基线漂移

当前工作树与既有专项 agent/测试并非完全一致：

- `test_warden_deployment.py` 仍记录二段 `0.65`、冲刺 `0.46`、潜行一段 `0.46` 等旧命中点；当前 `WardenMob.py` 分别是 `0.70`、`0.70`、`1.04`。
- 既有测试期望多数一次性动画写入 `anim_time_update` 并与状态时长严格相等；当前 BBModel/导出 JSON 多数未包含这些速率覆盖。
- 当前监守者冲刺 `AttackTime=0.6`，但攻击盒在 `0.7` 创建。Mob 控制器会把攻击授权至少延到最新攻击计时器后 `0.05s`，所以运行时仍可创建；这仍应由审计报告为字段漂移，而不是作为新配置范式复制。

使用本技能时：以用户确认的当前运行表现作为样本，但必须报告以上漂移。除非用户明确要求更新基线，不得擅自改生产配置、BBModel、导出动画、专项 agent 或旧测试。
